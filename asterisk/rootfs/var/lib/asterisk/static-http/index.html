Asterisk Architecture & Port Reference

        

          

            SIP UDP/TCP Signaling
            Port 5060 (Local LAN deskphones & ATAs)
          

          

            SIP TLS Encrypted Signaling
            Port 5061 (Secure SIP over TLS)
          

          

            HTTP / Ingress / WebSocket
            Port 8088 (Home Assistant Ingress, /ws, and HTTP Web UI)
          

          

            HTTPS / WSS (Recommended for Direct Access)
            Port 8089 (TLS WebSocket /ws and HTTPS Web UI at /static/index.html)
          

          

            RTP Media Streams (UDP)
            Ports 10000 - 20000 (Two-way audio/video packets)
          

          

            Asterisk Manager Interface (AMI)
            Port 5038 (Control protocol used by Home Assistant integration)
          

          

            Custom Config Directory (Add-on)
            /addon_configs/b35499aa_asterisk/asterisk/custom/
          

          

            Custom Config Directory (Docker)
            /config/asterisk/custom/
